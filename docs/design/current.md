# 既存デザインの調査（2026-11-13時点）

デザイン変更の前に、今のtoshLabの画面構成・見た目のルール・動きを整理したもの。変更方針は [design-system.md](design-system.md) を参照。

---

## 1. ページとルート

ルートは `routes/public.php`（`web.php` は読み込むだけ）。管理画面 `/admin` は Filament が持つので、今回のデザイン変更の対象外。

| URL | ルート名 | Controller | Blade |
|---|---|---|---|
| `/` | `home` | `HomeController` | `home.blade.php` |
| `/works/{work:slug}` | `works.show` | `WorkController@show` | `works/show.blade.php` |
| `/blog` | `posts.index` | `PostController@index` | `posts/index.blade.php` |
| `/blog/{post:slug}` | `posts.show` | `PostController@show` | `posts/show.blade.php` |
| `POST /inquiries` | `inquiries.store` | `InquiryController@store` | （トップの `#contact` にリダイレクト） |

### その他のページ

| ページ | 構成 |
|---|---|
| ブログ一覧 | h1「ブログ」＋ `<x-post-card>` の一覧＋ページ送り |
| ブログ記事 | 日付・カテゴリ → h1タイトル → Markdown本文（`.prose-post`）→ 相談への誘導の帯 → 一覧へ戻るリンク |
| 実績詳細 | ラベル・タグ → h1 → 概要 → サムネイル → デモ／GitHubのボタン → Markdown本文 → 一覧へ戻るリンク |

### 見出しの順番

h1 はページに1つずつ。トップは h1 → 各セクション h2 → カード h3 の順で、飛び級はない。
気になる点：プロフィールの名前・強み、ブログカードのタイトルは `<p>` で書いている（見出しにするかは変更時に検討）。

## 3. 今の配色・フォント・文字サイズ・余白

Tailwind CSS 4 なので `tailwind.config.js` はなく、`resources/css/app.css` の `@theme` に定義している。

### 配色（ライトのみ。ダークモードは無い）

| トークン | 色 | 使い道 |
|---|---|---|
| `paper` | `#F7F5F0`（生成り） | ページ背景 |
| `band` | `#EFEBE2` | ファーストビュー・お問い合わせの帯、タグの背景 |
| `ink` | `#1C1C1C` | 見出し・強い文字 |
| `body` | `#444444` | 本文 |
| `muted` | `#5C5A55` | 補足・日付 |
| `line` | `#DAD6CC` | 枠線・区切り線 |
| `placeholder` | `#E8E4DA` | 画像が無いときの枠 |
| `field` | `#C9C4B8` | 入力欄の枠 |
| `accent` | `#2E6B4E`（深い緑） | ボタン・英字見出し・料金・リンク |
| `accent-dark` / `accent-soft` | `#1F4C37` / `#E1ECE5` | ホバー時／提案デモのラベル |
| `sample` / `sample-soft` | `#6B4510` / `#F4ECD9` | サンプルのラベル |

カードは白（`bg-white`）＋ `line` の枠線＋角丸8px。

### フォント

- Noto Sans JP（400・500・700）を Google Fonts から読み込み。英字も同じフォント
- 行間は本文 1.8（ブログ本文 1.9）

### 文字サイズ

段階のルールはなく、その場ごとにpxで指定している（`text-[13px]` など）。使われているサイズは次の13種類。

| 用途 | サイズ |
|---|---|
| ラベル・小さな注記 | 11px・12px・13px |
| 本文・カードの説明 | 14px・15px・16px |
| カードの見出し | 17px・18px |
| 小見出し・名前 | 20px・22px |
| 料金・セクション見出し | 26px（スマホ）／30px（PC） |
| 記事タイトル | 28px／32px |
| h1 | 32px（スマホ）／44px（PC） |

### 余白・幅

- 最大幅：1120px（ブログ記事 760px、実績詳細 860px）、左右の余白 24px
- セクションの間：上に 96px（`pt-24`）。下の余白は次のセクションが持つ
- カードの中：24〜32px
- カードの並び：flex-wrap ＋ 基準幅（240px／320px／480px）で折り返す

## 4. JavaScript・アニメーション

- `resources/js/app.js` は Laravel 標準の `bootstrap.js`（axios の読み込み）だけ。**独自のJavaScriptは無い**
- アニメーションは CSS だけ：
  - `html { scroll-behavior: smooth }`（ページ内リンクのなめらかなスクロール）
  - リンク・ボタンの色の `transition`
  - FAQ の「＋」が開くと45度回る
- `prefers-reduced-motion` への対応は未実装（今は大きな動きが無いので実害はない）
- JavaScriptが動かなくても全部表示される（文字はすべてBladeで出力）

## 5. 参考サイトの方向性と比べて

参考にするのは「余白の取り方」「文字の大きさの強弱」「動きのなめらかさと控えめさ」の方向性だけ。

### 変えた方がよい点

| 今 | 理由・方向性 |
|---|---|
| 生成り色の背景と帯 | 「白（ダークでは黒）が基調」に合わせる。帯の色分けをやめて、余白と細い線で区切る |
| カードの枠線が多い | 全セクションが「白いカード＋枠線」で同じ見た目になり、画面がにぎやか。線を減らして、一覧は区切り線で見せる |
| 文字サイズが13種類あって強弱が弱い | h1が44pxで、本文との差が小さい。段階を決めて、大きい見出しはもっと大きく、それ以外は控えめにする |
| セクションの間が96px | 参考サイトは余白がかなり広い。PCでは140〜160px程度に広げて、1画面に1つの話題が入るくらいにする |
| ダークモードが無い | 要件。OSの設定に合わせ、切り替えも付ける |
| 動きがほぼ無い | 表示時のフェードとスライドを控えめに足す |
| 文字サイズのpx直書き | トークン化して、ライト／ダークや今後の調整を楽にする |

### 残した方がよい点

- **情報の順番と文章**：業務効率化を先頭に置く構成、料金の目安、相談の流れ、FAQ（相談しやすさに直結する）
- **実績のラベルでの区別**（サンプル／提案デモ／制作実績）：信頼につながる
- **アクセントカラーが1色**だけというルール
- **CTAが2つ**（ThreadsのDMとフォーム）と、最後にお問い合わせを置く流れ
- **Noto Sans JP**：日本語の読みやすさ。英字だけ別のフォントを足す案はあり（design-system.md）
- スキップリンク、`<details>` のFAQ、フォームの `<label>` など、アクセシビリティのための作り
- 参考サイトのような暗い写真の背景・明朝体の大きな名前・縦書きの見出しは、**個人店やチームの方にとって読みにくく、真似にも見えやすいので採用しない**
