**改訂2**：オーナーの希望で、モックのHTMLとCSSをほぼそのままBlade化し、そこに今の文章・コンテンツを入れる進め方に変更した。そのため ④〜⑨ の見た目は ② でまとめて行い、残りは ③（アニメーション）・⑩（仕上げ）・⑪（英語版）。ヘッダーにはモックと同じメニュー（Works / Profile / Contact）も置く。

## 0. 方針

- **見た目はモックに合わせる**：白（ダークは黒）基調、アクセント1色。極太の英字の大見出し、細い線で区切る一覧、等幅フォントの小さな注記、丸いボタン
- **文章と構成は今のサイトのまま**：FOR YOU・実績・サービスと料金・相談の流れ・プロフィール・経験・スキル・ブログ・FAQ・お問い合わせ。モックにしかない文章（「東京拠点」、サイトに無い実績など）は使わない
- **名前は toshLab / tosh**（実名は出さない）
- **文字はすべてBladeで出力**。モックの「JavaScriptで文字を入れ替える」仕組み（言語切り替え・実績の一覧）は使わず、Bladeで出す。英語版は `/en` のページとして別に作る（§3 ⑪）
- **下のメニューバー**（今いる場所が光る）を追加する。上のヘッダーは、ロゴ・言語・テーマの切り替えだけ
- 動きは「ふわっと」「清潔」。モックと同じ、下から24pxの浮き上がりを基本にする

## 1. 基本ルール

### 1-1. 配色（モックの値）

| トークン | ライト | ダーク | 使い道 |
|---|---|---|---|
| `bg` | `#FFFFFF` | `#0E0E0E` | ページ背景 |
| `ink`（モックの `fg`） | `#0A0A0A` | `#EDEDEA` | 文字・見出し・黒い丸ボタン・実績一覧の上の太い線 |
| `body` | `#2B2B2B` | `#D6D6D2` | 長めの本文（`ink` だと強すぎる所） |
| `muted` | `#5C5C5C` | `#9C9C98` | 等幅の注記・説明・日付 |
| `line` | `#E6E6E6` | `#2A2A2A` | 区切り線・枠線 |
| `surface`（モックの `panel`） | `#F4F5F4` | `#1A1A1A` | アイコンの枠・入力欄の背景・コードブロック以外の面 |
| `accent` | `#1F5C45` | `#5DBB94` | ロゴとタイトルの「.」、受付中の丸、リンクの強調、今いる場所の光。**1色だけ** |
| `accent-soft` | `#E6EFEB` | `#15241E` | 提案デモのラベル、選択中の背景 |
| `danger` | `#B42318` | `#F97066` | フォームのエラー |

- ボタンはモックと同じく、**黒い丸ボタン（ダークでは白）**が基本。アクセントの塗りは使わない
- 文字のコントラスト比は4.5:1以上（`muted`：ライト6.6:1／ダーク7.0:1）
- 実績のラベル：制作実績＝`ink` の塗り、提案デモ＝`accent-soft`、サンプル＝`line` の枠線。文字で「サンプル」と書くので色だけに頼らない

### 1-2. ダークモード

- 初期値はOSの設定、選んだものは `localStorage` に保存（モックと同じキー `theme`）
- `<html data-theme>` で切り替え。`<head>` の数行で描画前に決める（ちらつき防止）
- JavaScriptが無いときは `@media (prefers-color-scheme: dark)` でOSの設定に従う
- 色の変化は CSS の `transition`（0.4秒、モックと同じ）

### 1-3. フォント

| 用途 | フォント | 太さ |
|---|---|---|
| 英字の大見出し・ロゴ・英字全般 | Inter | 400・500・600・800 |
| 日本語 | Noto Sans JP（Interに無い文字を表示） | 400・500・700 |
| 注記・番号・メニュー（モックの `.mono`） | JetBrains Mono | 400・500 |

本文は `Inter, 'Noto Sans JP'` の順（英数字はInter、日本語はNoto Sans JP）。日本語の改行は `word-break: auto-phrase`。

### 1-6. 見出しとSEO

モックは大きな英字（「Works」など）だけが見出しだが、日本語の見出しの文章を残すため、次のようにする。

- **h1**：今のキャッチコピー「Excelや手作業の業務を、使いやすいシステムに。」を、ファーストビューの `text-statement` の位置に置く。大きな「tosh / Lab.」はロゴとしての表示（`<p>`）にする
- **h2**：大きな英字と日本語の見出しを1つの h2 に入れる
  例：`<h2><span lang="en">Works</span><span>制作実績</span></h2>`（日本語は等幅の注記の位置に小さく表示）
- **h3**：一覧の各項目名
- title・meta・OGP は変えない（`/en` に `hreflang` を追加するときは事前に相談する）

## 2. 部品

### 2-1. ヘッダー（モックどおり）

- 左：ロゴ「toshLab.」（Inter 800、15px、字間0.08em、「.」がアクセント）
- 右：言語の切り替え（JA / EN の丸いトグル。**`/` と `/en` へのリンク**。JavaScriptで文字は入れ替えない）、テーマの切り替え（44pxの丸いボタン、月／太陽のアイコン）
- メニューは下のバーにまとめるので、ヘッダーには置かない
- 上に固定、下に1pxの `line`

### 2-2. 下のメニューバー

- 画面下の中央に固定（下から16px＋`env(safe-area-inset-bottom)`）。背景は `bg` を少し透かしたうえでぼかし、`line` の枠、角丸999px
- メニュー：Works（実績）／Services（サービス）／Profile（経歴）／Blog（ブログ）／Contact（相談する）。JetBrains Mono 12〜13px。日本語の補助表記はスマホでは省略
- 今いる場所：アクセント色の1px枠と、ごく淡い光（アクセント色の透明度20%程度）の囲みが、メニューの間を横にすべって移動する（0.45秒）
- 判定：各セクションが画面の中央を通過しているとき。Profile は `#about`・`#experience`・`#skills` のどれか
- 他のページ：ブログでは Blog、実績詳細では Works を光らせる（Bladeで `aria-current="page"`）
- JavaScriptが無いときは普通のリンク。reduced-motion では動きなしで切り替え
- ページの下にバーの高さ分の余白を足して、フッターやフォームが隠れないようにする

### 2-3. セクションの見出し（モックの `.sec-head`）

- 左に英字の大見出し（`text-section`）、右に等幅の注記「(01) — 制作実績」。番号はセクションの順番
- FOR YOU は「For you」、サービスは「Services」、経験は「Experience」、スキルは「Skills」、ブログは「Blog」、FAQは「FAQ」

### 2-4. 一覧の行（モックの `.wrow`）

- 4列：番号（等幅）／項目名＋説明／技術・補足（等幅）／矢印
- ホバーで左に16pxずれて、矢印が右に6px動く（0.35秒、CSS）
- スマホ（720px以下）：3列（番号／項目名＋説明／矢印）にして、技術の列は隠す
- 使う所：FOR YOU（矢印なし）、実績、サービス（右の列に料金）、実務での経験、ブログ（番号の代わりに日付）

### 2-5. ボタン

| 種類 | 見た目 | 使い道 |
|---|---|---|
| 黒い丸ボタン（モックの `.mail-btn`） | `ink` の塗り、`bg` の文字、22px×40px、18px・600 | お問い合わせ（ThreadsのDM）、フォームの送信 |

## 3. アニメーション

- **ふわっと**：下から24px＋不透明度0→1、0.8秒、`power3.out`。一覧は1行ずつ0.06秒の時間差
- GSAP：`timeline`（ファーストビュー）、`ScrollTrigger`・`ScrollTrigger.batch`（表示）、`matchMedia`（reduced-motion）
- ホバー（行のずれ・矢印・不透明度0.7）と、テーマの色の変化は CSS
- 隠してから出す仕組みは `html.js-motion` のときだけ有効。GSAPが3秒以内に動かなければ全部表示。reduced-motion では最初から全部表示
- 慣性スクロールは使わない
- ファイル：`resources/js/animations/` に `index.js`・`hero.js`・`reveal.js`・`dock.js`（テーマの切り替えは `resources/js/theme.js`）。Bladeとのつなぎは `data-` 属性だけ（`data-hero-line`・`data-hero-item`・`data-reveal`・`data-reveal-item`・`data-dock`）
- ヘッダーはモックどおり最初から下線があるので、スクロールで変える動き（`header.js`）は作らない
- トップの「今いる場所」は `aria-current="location"`、他のページは Blade の `aria-current="page"`
